## 🌻 What is "Aaj Kay Lavayche"?

**"Aaj Kay Lavayche" (Marathi: *आज काय लावायचं?* / *"What should I sow today?"*)** is a lightweight, offline-first command-line garden planner tailored specifically for the hot semi-arid climate of **Solapur, Maharashtra**.

Most gardening apps and AI assistants demand a persistent internet connection, trap you in endless infinite-scrolling feeds, or rely on expensive, latency-heavy cloud APIs. 

**Aaj Kay Lavayche changes that with a strict "Touch Grass" philosophy:**
1. Run **one simple command** from your terminal.
2. Get **three crisp recommendations**, sowing steps, and a Solapur-specific watering tip generated by a local open-weight LLM (or the built-in offline rules engine).
3. **Close your laptop and go get your hands dirty outside.**

## 🚜 Solapur Climate & Agro-Ecological Context

Solapur features a **hot semi-arid climate (BSh)** characterized by dry winds, high summer temperatures, and distinct agricultural seasons:
- **Kharif (पावसाळी / Monsoon):** June to September — Cucurbits, Solanaceae (Tomato, Chilli, Brinjal), Cluster beans.
- **Rabi (हिवाळी / Winter):** October to February — Leafy greens (Methi, Palak, Kothimbir), Garlic, Onions, Radish.
- **Summer (उन्हाळी / Summer):** March to May — Heat-tolerant gourds, Cowpeas, Okra, Mint with afternoon shading.

## 📦 Installation & Setup

### 1. Prerequisites
- **Python 3.10+**
- **[Ollama](https://ollama.com)** (installed on your machine)

### 2. Pull the Lightweight Open-Weight Model
Aaj Kay Lavayche defaults to Meta's lightweight **Llama 3.2 3B**, which runs smoothly on laptops with just 8GB RAM:
```bash
ollama pull llama3.2:3b
```

### 3. Clone Repository & Install Python Dependencies
```bash
git clone https://github.com/your-username/aaj-kay-lavayche.git
cd aaj-kay-lavayche
pip install -r requirements.txt
```

## 🚀 Quickstart & Usage

### 1. Daily Planning (Default: Marathi Devanagari)
```bash
python planner.py
```

### 2. Balcony / Container Garden Mode (`--container`)
Filters only plants suitable for pots and grow bags (excludes deep-root or sprawling farm crops like Moringa or field bottle gourds):
```bash
python planner.py --container
```

### 3. English Language Mode (`--lang en`)
```bash
python planner.py --lang en --container
```

### 4. Planning Ahead for Future Dates (`--date YYYY-MM-DD`)
```bash
python planner.py --date 2026-11-01 --container
```

### 5. Swapping Models (`--model`)
```bash
python planner.py --model qwen3.8:latest
```

### 6. Logging Outdoor Activities (`--log` & `--history`)
Record your sowing sessions without opening a browser:
```bash
python planner.py --log "Sowed methi in 10-inch terracotta pot with vermicompost"
python planner.py --history
```

### 7. Instant Rule-Engine Mode (`--offline-only`)
Skips the LLM inference step and uses the local curated catalog directly:
```bash
python planner.py --offline-only
```

## ✏️ How to Add Your Own Plants / Regions

All plant data is stored in [`plants.json`](file:///plants.json). You can easily add native varieties or customize for your city:

```json
{
  "id": "mirchi",
  "marathi_name": "मिरची",
  "english_name": "Green Chilli",
  "sow_months": [1, 2, 5, 6, 7, 9, 10],
  "days_to_harvest": "65-80 days",
  "sunlight": "Full Sun (6+ hrs)",
  "water_needs": "Moderate (Allow topsoil to dry slightly)",
  "container_friendly": true,
  "short_tip": "कुंडीत पाण्याचा निचरा उत्तम ठेवा. पानांचा चुरडा-मुरडा रोखण्यासाठी आंबट ताक फवारा."
}
```
